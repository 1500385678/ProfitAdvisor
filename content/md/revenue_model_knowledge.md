# 收入模型图谱

> 知识图谱 1/7 · Phase 0 #2 第一份样本
> 覆盖订阅 / 交易 / 平台 / 广告 4 大主流收入模式 + 衍生指标
> 数据源:主计划 1.3 资产盘点 + 行业通用认知

## 订阅收入

按周期(年/月/季)持续收费。锁定现金流、提升 LTV,但需要持续交付价值防流失。

### 适用行业

- SaaS
- 视频流媒体
- 在线教育
- 会员制零售(山姆/Costco)

### 关键指标

- MRR / ARR
- 续费率(NRR)
- Churn

## 交易收入

按次/按件收取。简单直接、毛利即收入,需要规模或高客单支撑利润。

### 适用行业

- 电商零售
- 餐饮
- 硬件销售

### 关键指标

- GMV
- 客单价
- 复购率

## 平台收入

撮合供需双方抽佣。网络效应是核心壁垒,需要双边密度。

### 适用行业

- 外卖(美团/饿了么)
- 出行(滴滴)
- 电商平台(淘宝/拼多多)

### 抽佣模型

```
take_rate = GMV × commission_rate
platform_revenue = take_rate - subsidy - payment_fee
```

## 广告收入

出售流量/曝光/转化。依赖用户规模与精准度,数据资产是护城河。

### 适用行业

- 搜索(百度/Google)
- 社媒(微博/小红书)
- 信息流(抖音)

### 关键指标

- eCPM
- CTR
- 填充率

## 收入公式

### 订阅收入公式

```
MRR = subscribers × ARPU
ARR = MRR × 12
NRR = (starting_MRR + expansion - churn - contraction) / starting_MRR
```

## 收入模型选择

不同生意阶段匹配不同模型,小生意首选交易,平台期押注订阅或平台。

### 决策树

- 现金流稳 → 订阅
- 流量大 → 广告
- 双边网络 → 平台
- 实物交付 → 交易

## 收入优化

从模型选择到定价到漏斗到留存,4 个杠杆联动调优。

### 杠杆清单

- 模型迁移(交易 → 订阅)
- 价格段拓展
- 交叉销售
- 复购激励

## 收入红旗

- 续费率 < 80%
- CAC > LTV
- ARPU 连降
- 退款率 > 5%
